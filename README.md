# Sıla Yolu

Avrupa'dan Türkiye'ye arabayla gidenler için Android uygulaması (Türkçe / Almanca).

- Güzergah seçimi ve Google Maps navigasyonu
- Ülke ülke vinyet, hız sınırı, para birimi ve acil numaralar
- Yolculuk öncesi kontrol listesi
- Yakındaki benzinlik, motel, restoran vb. arama

APK: Releases bölümünden `Sila-Yolu.apk`.
